# Music Comment Manager

本地音乐文件**备注管理工具**，基于浏览器的 Web 界面，无需安装额外客户端。

支持批量查看、搜索、编辑、删除备注，查看和编辑内置对中文/日文**乱码备注**的清理。

---

## 功能一览

| 功能 | 说明 |
|---|---|
| 🔍 **渐进式扫描** | 后台扫描音乐库，实时显示进度，扫描中即可浏览已发现的结果 |
| 📋 **分页列表** | 每页 30 / 50 / 100 / 200 条，支持跳页 |
| 🔎 **搜索关键词** | 可限定搜索范围：全字段 / 曲名 / 备注 / 路径 |
| ⊘ **排除关键词** | 实时过滤掉备注中含特定关键词的条目 |
| ↕️ **多列排序** | 按曲名、格式、备注内容升降序排序 |
| ✏️ **编辑备注** | 点击备注文字打开详情弹窗，通过「编辑备注」进入编辑器，修改后需二次确认才写入文件 |
| 🗑️ **清空备注** | 详情弹窗一键清空 / 多选批量清空 |
| 🔑 **关键词操作** | 输入关键词（支持正则），可选：① 仅删除关键词本身 ② 清空整条备注；实时预览匹配数量 |
| 📂 **打开所在文件夹** | 调用系统文件管理器并高亮定位到该音乐文件 |
| 🧹 **乱码清理** | 读取时自动检测并剥离 GBK / Shift-JIS 等遗留编码造成的乱码后缀 |
| 🔄 **重新扫描** | 扫描完成后可一键重扫，无需重启服务 |

| 格式 | 扩展名 | Comment 字段 |
|---|---|---|
| FLAC | `.flac` | VorbisComment `comment` |
| MP3 | `.mp3` | ID3v2 `COMM` 帧 |
| Apple Lossless / AAC | `.m4a` | MP4 `©cmt` |
| Ogg Vorbis | `.ogg` | VorbisComment `comment` |
| Opus | `.opus` | VorbisComment `comment` |
| Monkey's Audio | `.ape` | APEv2 `Comment` |
| WavPack | `.wv` | APEv2 `Comment` |
| WAV / AIFF | `.wav` `.aiff` `.aif` | ID3v2 `COMM` 帧 |

## 环境要求

- Python **3.10+**
- 依赖库：`flask` `mutagen`

```bash
pip install flask mutagen
```

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/geekieo/music-comment-mgr.git
cd music-comment-mgr

# 安装依赖
pip install flask mutagen

# 启动（自动打开浏览器）
python music_comment_mgr.py ~/Music

# 指定端口
python music_comment_mgr.py ~/Music --port 9000

# 不自动打开浏览器
python music_comment_mgr.py ~/Music --no-browser
```

启动后访问 `http://localhost:8765`（默认端口）。

## 使用说明

### 查看备注
- 点击表格中的**备注列文字**，弹出完整备注详情弹窗
- 详情弹窗显示文件格式、相对路径和完整备注内容

### 搜索关键词
- **搜索框**：正向筛选，支持按「全字段 / 曲名 / 备注 / 路径」限定范围
- **排除框**：在搜索结果中进一步排除备注含特定关键词的条目，两者可同时使用
- 输入后 300ms 自动触发，点击 ✕ 清除

### 编辑备注
1. 点击行备注，在详情弹窗中点击「编辑备注」
2. 在文本框中修改内容（留空则清空备注）
3. 点击「确认保存」→ 二次确认弹窗 → 写入文件

### 关键词操作
1. 点击工具栏「**关键词操作**」
2. 输入关键词（默认字面匹配，勾选「正则模式」可用正则表达式）
3. 实时预览：显示将匹配的文件数量和前几条文件名
4. 两种执行方式：
   - **删除关键词**：从备注中移除该词，保留其余内容
   - **清空匹配备注**：将整条备注清空

### 批量清空
1. 勾选行首复选框（支持跨页保留选中状态）
2. 点击「清空已选」→ 二次确认 → 批量写入

### 打开文件夹
- 点击列表行最右侧的 **📂** 按钮
- Windows：在资源管理器中高亮显示该文件（`explorer /select,`）
- macOS：在 Finder 中高亮显示（`open -R`）
- Linux：打开文件所在目录（`xdg-open`）

## 乱码备注自动清理

部分旧版音乐软件在写入 tag 时存在双重编码问题：同一段文字同时以 UTF-8 和 GBK / Shift-JIS 字节写入，后者被当作 Latin-1 读取后呈现为乱码。

**示例（修复前）：**
```
电影《NANA》插曲 µçÓ°¡¶NANA¡·²åÇú
```

**修复后：**
```
电影《NANA》插曲
```

本工具在读取时自动检测并剥离此类乱码后缀，支持 GBK、GB18030、Big5、CP932、Shift-JIS、EUC-JP、EUC-KR 七种编码的识别。**原始文件不受影响**，仅在显示和写入时使用清理后的内容。

---

## 注意事项

- **操作不可撤销**：清空或修改备注后直接写入音乐文件，建议重要操作前备份文件
- **仅处理含备注的文件**：无备注的文件不会出现在列表中
- **跨平台**：在 Windows、macOS、Linux 上均可运行
- **数据仅在内存中**：重启服务后需重新扫描（可点击「重新扫描」按钮而无需重启）
- 扫描速度取决于文件数量和磁盘速度，2000～3000 首约需 10～30 秒
